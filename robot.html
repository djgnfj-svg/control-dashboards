이기종 로봇 9종의 제각각인 데이터 포맷을 기종별 JSON 스키마 어댑터와 공용 파서로 묶어 실시간 수집 통합

문제

설계

  • 서버와 브라우저가 같은 스키마를 읽는다
구현

  • 설정은 mtime 캐시로 재시작 없이 반영
  • 짧은 패킷 · 미등록 로봇은 버리고 선언 밖 바이트는 무시
결과

  • 펌웨어 필드 추가 = JSON 한 줄 · 골든 테스트 18

"hunter": {
  "cmd_name": "ROBOT_DATA", "packet_size": 30,
  "fields": [
    {"name": "mos_id",  "offset": 2,  "type": "u8"},
    {"name": "pos_x",   "offset": 3,  "type": "f64", "round": 6},
    {"name": "pos_y",   "offset": 11, "type": "f64", "round": 6},
    ...
    {"name": "error",   "offset": 29, "type": "u8"}
  ]
}
def interpret(payload, fields):
    out = {}
    for f in fields:
        t, off = f['type'], f['offset']
        if t == 'u8':
            val = payload[off]
        else:
            val = struct.unpack(_TYPE_FMT[t],
                  payload[off:off + _TYPE_SIZE[t]])[0]
            if f.get('int'):   val = round(val)
            elif 'round' in f: val = round(val, f['round'])
        out[f['name']] = val
    return out
스키마
  • 기종마다 이름 · 오프셋 · 타입만 적는다
  • 닮은 기종은 fields_ref 로 빌려 쓴다
파서
  • 기종을 모르는 루프 하나 — 선언대로 잘라 읽는다
  • little-endian 고정 · 표시 정밀도는 round
안전장치
  • 기동 때 마지막 필드 끝 = packet_size 검사
  • cmd 는 타입 교차 확인용 — 어긋나면 버린다
브라우저
  • 같은 JSON 을 /api/config 로 받아 같은 루프 + 기종별 shape()
경력 ④ 태스크 할당

두 층 큐

접수 순서로만 돌던 태스크 큐를 배정·로봇별 발행 두 층으로 나누고 우선순위를 넣어, 평소엔 FIFO를 유지하고 긴급 미션만 앞세우도록 구현

문제
  • 접수 순서 큐 하나 — 고장 · 갈 수 없는 로봇에도 배정
  • 급한 일을 앞세울 길이 없음
설계
  • 무엇을 할지(현장별 풀)와 누가 할지(로봇별 큐)를 두 층으로
구현
  • 가까운 가용 로봇에 배정, 다섯 조건은 뺀다
  • 안정 삽입 정렬 — 같은 우선순위는 도착 순, 실행 중인 일은 안 밀린다
  • 1초 틱이 만료 · 배정 · 발행을 뮤텍스 안에서, 네트워크 발행은 밖에서
결과
  • 평소엔 FIFO 그대로 · 우선순위는 API 로 열어 둠

원인 측정

  • 테이블은 입력 50ms 미만이라 제외
설계
  • 행을 불변으로 갱신하고, 참조가 바뀐 행만 다시 그린다
구현

  • 레이어 켜고 끄기는 떼지 않고 setVisible

경력 ② 맵 에디터 · 구현

참조 비교 diff

export function diffByKey(prev, next, keyFn) {
  const prevByKey = new Map(prev.map(r => [keyFn(r), r]));
  const nextKeys = new Set(), added = [], updated = [];
  for (const row of next) {
    const key = keyFn(row); nextKeys.add(key);
    const old = prevByKey.get(key);
    if (old === undefined) added.push(row);
    else if (old !== row)  updated.push(row); // 참조가 다르면 바뀐 것
  }
  const removed = [...prevByKey.keys()]
    .filter(k => !nextKeys.has(k));
  return { added, updated, removed };
}
