아키텍처

무거운 건 미리, 키는 서버에만

  • 공공 API 의 차이는 브라우저 데이터 층에서 흡수 — 화면은 한 모양만 받는다
  • 라이다는 미리 줄여 두고, 브라우저는 6MB 만 받는다
로봇 데이터

368MB 라이다를 브라우저에 올리기

  • 원본 3,067만 점은 지도·3D 보기에 올릴 수 없었다
  • 0.25m 복셀 평균으로 점을 줄였다
  • 원점이 다른 라이다 좌표를, 주행 경로가 나무 열 사이를 지나도록 FFT 상관으로 자동 정합

3,067만 → 85만 점368MB → 6MB

0.4m 이내회전을 ±1.5° 흔들어도 정합

정확성 · 원칙

화면의 수치는 원본과 맞춘다

  • 로봇 경로가 필지 밖으로 밀려 보여 위성영상과 대조 — 로봇이 맞고 지적도가 15.6m 밀려 있었다
  • 1도당 거리를 고정값으로 쓰던 면적을 위도별 측지 계산으로 바꾸고, 화면 수치 10개를 원본과 대조
  • 가짜 농지·가짜 수치가 섞인 데모의 목업을 전부 지우고 실제 API 가 붙은 것만 표시
  • 브라우저에 드러나던 인증키를 중계 서버로 옮겼다
  • 배포해도 옛 목업이 뜨던 원인은 같은 출처 다른 사이트의 서비스워커 — 이 경로에만 걸리는 서비스워커로 이겼다
